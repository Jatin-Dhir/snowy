# Taily

A fast, soft, offline-first expense tracker. Log an expense in under three seconds — numpad up instantly, tap a tag, done. Everything stays on your device.

## What it does

- **3-second logging** — amount-first numpad, one-tap tag chips, save on touch
- **Money in & out** — spent / received, with everyday tags you can fully customize
- **Budgets with pace** — monthly + per-category envelopes, over-budget warnings and notifications
- **Insights** — where it went, six-month trend with forecast, smart notes
- **Lent & borrowed** — note who owes you, get reminded, keep the settled record
- **On-device intelligence** — learns your notes and files untagged expenses automatically
- **Themes** — 8 accent colors (including a creamy space) × light/dark × three surface styles (Soft neumorphic, Clay, Bubble)
- **Haptics & sounds** — real haptic engine feedback with individual toggles
- Local-first: no account, no cloud, no ads. Export CSV anytime.

## Three ways to get Taily

| Channel | Where | Updates |
| --- | --- | --- |
| Web app (iPhone, anything with a browser) | https://taily.jatindhir.com, installable from the browser | automatically, on every push to `main` |
| Google Play | see [store/play](store/play/README.md) | through Play |
| Sideloaded APK | this repository's **Releases** | in-app, once a day (Settings → Check for updates) |

Only the sideloaded APK polls GitHub for updates. The build mode decides: `vite build` is the sideload channel,
`--mode play` is Play, `--mode web` is the hosted web app (see `src/lib/distribution.ts`).

## Build

```bash
npm install
npm run build                       # sideload web bundle
npx cap sync android
cd android && ./gradlew assembleSideloadDebug
```

- Web app: `npm run build:web` (deployed by `.github/workflows/deploy-web.yml`)
- Play Store build: `npm run build:play`, then `npx cap sync android` and `./gradlew bundlePlayRelease` (details in [store/play](store/play/README.md))
- Web dev server: `npm run dev`. Icons are generated by `node scripts/gen-icons.mjs` (zero-dependency PNG writer).

Built with React + TypeScript + Vite + Dexie, wrapped with Capacitor.
